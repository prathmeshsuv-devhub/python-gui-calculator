# 🧮 Python Scientific GUI Calculator

A user-friendly scientific calculator application developed using **Python and Tkinter**.  
The application provides basic arithmetic operations along with scientific functions, calculation history, keyboard support, and error handling.

## 🚀 Features

### Basic Operations
- Addition
- Subtraction
- Multiplication
- Division
- Decimal calculations
- Parentheses

### Scientific Operations
- Square Root (√)
- Square (x²)
- Sine (sin)
- Cosine (cos)
- Tangent (tan)
- Pi (π)
- Power (^)
- Percentage (%)

### Additional Features
- Positive/Negative (+/-)
- Backspace
- Clear display
- Calculation history
- Clear history
- Keyboard support
- Error handling
- Modern dark-themed GUI

## 🛠️ Technologies Used

- **Python**
- **Tkinter** – Graphical User Interface
- **Math Module** – Scientific calculations
- **Git & GitHub** – Version control and project hosting

## ▶️ How to Run

### 1. Install Python

Make sure Python is installed on your computer.

### 2. Open the Project

Open the project folder in **VS Code**.

### 3. Open Terminal

Run:

```bash
python gui_calculator.py
```

The calculator window will open.
