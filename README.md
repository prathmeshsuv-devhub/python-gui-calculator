# 🧮 Python GUI Calculator

A simple and user-friendly calculator application developed using Python and Tkinter.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Percentage
- Positive/Negative
- Backspace
- Clear
- Calculation History
- Keyboard Support
- Error Handling
- Modern GUI

## Technologies Used

- Python
- Tkinter

## How to Run

1. Install Python.
2. Open the project in VS Code.
3. Open the terminal.
4. Run:

```bash
python gui_calculator.py
